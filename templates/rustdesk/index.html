:: Como funciona ::
  1. O servidor roda dois containers Docker:
    • hbbs — rendezvous (encontro) e sinalizacao
    • hbbr — relay (so usado quando NAT impede P2P)
  2. Ao subir, o hbbs gera o par de chaves id_ed25519 » id_ed25519.pub em /var/lib/rustdesk-data/. A publica fica visivel ao lado.
  3. Voce informa aqui o IP/dominio publico do servidor (porta 21115/21116/21117 abertas no firewall externo).
  4. O painel gera um instalador .exe ou um .bat que ja vem com:
    • endereco do seu servidor
    • chave publica
  5. Voce distribui o instalador para os usuarios — eles nao precisam configurar nada.

NAT/Firewall externo: abra TCP 21115, TCP+UDP 21116, TCP 21117, TCP 21118, TCP 21119 do seu IP publico para o IP interno 172.16.3.100.
